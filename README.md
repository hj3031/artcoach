# 곁 · 나의 그림 코치

그림 사진의 명암과 주요 색을 살펴보고, 다음에 시도할 연습을 제안하는 웹앱입니다.

## 사용 방법
1. `index.html`을 더블클릭해 브라우저에서 엽니다.
2. ‘새 그림 올리기’로 JPG, PNG, WEBP 사진을 선택합니다(최대 15MB).
3. 원하는 그림의 방향을 적고, 말투와 집중해서 볼 곳을 고릅니다.
4. ‘기초 코칭 시작하기’를 누릅니다. 흑백·대비 보기와 구도선도 사용해 보세요.

사진은 크기를 줄여 저장합니다. 마지막 그림 한 장, 입력 내용, 선택 항목과 기초 코칭 결과는 **현재 브라우저의 localStorage**에만 저장하며 외부로 보내지 않습니다. 다른 기기·브라우저에서는 이어 볼 수 없고, 브라우저 데이터를 지우면 사라집니다. 저장 공간 부족이나 저장 차단 시 화면에 안내가 나타납니다. 아래 ‘저장된 그림 지우고 예시로 돌아가기’를 누르면 내 그림과 입력 내용이 예시로 바뀝니다.

기초 코칭은 사진의 밝기와 선택 항목으로 만든 점검 안내이며, 그림의 내용을 이해하는 AI 분석이 아닙니다. 서버가 필요한 AI 대화와 최신 트렌드 검색은 이 버전에서 제공하지 않습니다.

## GitHub Pages에 올리기
이 폴더의 **내용물**을 저장소 맨 위에 올리세요. `index.html`, `assets` 폴더, 빈 `.nojekyll` 파일이 반드시 포함되어야 합니다. `node_modules`는 올리지 마세요.

GitHub 저장소에서 Settings → Pages → Deploy from a branch를 선택하고, 올린 브랜치(보통 main)와 맨 위 폴더(root)를 선택해 저장합니다. 별도로 빌드할 필요가 없습니다.

## 폴더 안내
- `index.html`: 처음 열리는 화면
- `assets/`: 바로 실행할 JavaScript, 화면 스타일, 예시 그림과 아이콘
- `src/`: 화면을 수정할 때 사용하는 원본 코드
- `build.mjs`, `package.json`, `package-lock.json`: 개발자가 실행 파일을 다시 만들 때 사용하는 파일
- `.nojekyll`: GitHub Pages에서 파일을 그대로 제공하게 하는 빈 파일
- `.gitignore`: Git으로 올릴 때 설치 파일·비밀 설정 등을 제외하는 목록

원본 코드를 수정한 경우에만 Node.js가 설치된 상태에서 `npm ci`, `npm run build`를 순서대로 실행하세요. 일반 사용이나 업로드에는 필요하지 않습니다.

파일을 직접 연 상태의 저장 동작은 브라우저에 따라 다를 수 있습니다. 설치된 Python이 있다면 이 폴더에서 `python -m http.server 8000 --bind 127.0.0.1`을 실행하고 브라우저로 `http://127.0.0.1:8000`을 열어도 됩니다. 미리보기와 실제 게시 주소의 저장 내용은 서로 별개입니다.

## 공개 전 확인
현재 파일에서 실제 개인정보는 발견하지 않았습니다. 나중에 추가하는 사진·파일에 이름, 연락처, 주소, 계좌번호가 없는지 확인하세요. `.gitignore`는 Git의 제외 목록일 뿐, 웹 화면에서 직접 올리는 파일을 검사하거나 보호하지는 않습니다.
